# 五页任务与计划设计

本说明对照当前源码，描述今天、明天、未来七天、四象限与月历的语义和交互边界。源码已接主界面，不代表已完成 Swift 编译或原生验收。状态见 [design-qa.md](../design-qa.md)，操作步骤见 [MANUAL_QA.md](../MANUAL_QA.md)。

## 1. 同一任务的五种入口

- **今天**用于执行：任务搜索、清单/日程、今日完成、计划轨和实际轨、计时、补录及实际记录编辑。
- **明天**显示下一个本地自然日。
- **未来七天**显示明天至第七个未来自然日，不含今天，不是滚动 168 小时。`SmartList.recent` 保留内部标识以兼容原数据。
- **四象限**读取当前工作区全部未完成任务，包含无计划、无截止的任务；不是某个日期的副本。
- **月历**展示完整周网格及所选日期的任务。网格包含相邻月的边缘日期；点击边缘日期会切换到该日期所在月份。

五页读取同一任务 ID 与持久化记录，检查器修改的是原任务。切换页面不复制任务。添加执行时段、修改计划、修改截止、记录实际专注和完成任务是不同操作，不能相互暗中代替。

## 2. 日期投影、计数和搜索

今天、未来面板和月历共享 `TodayExecutionProjection`；未来面板按 `PlanningHorizonProjection` 组合，月历由 `CalendarPlanningProjection` 组合。日期通过 `Calendar` 递增，适应跨月、跨年和夏令时。

### 哪些任务属于某天

排除其他工作区和已取消任务，按以下来源判断：

- 计划点位于当天，或计划范围与当天相交
- 至少一个执行时段与当天相交
- 截止时间落在当天
- 基础每日重复实例在当天已开始且未跳过，或当天已有完成实例
- 普通任务实际完成于当天，作为当天完成记录展示

仅仅“已经逾期”会进入今天的积压处理，但**不会自动铺满未来面板或月历**。月历即使选中今天也不自动带入仅逾期的积压；安排具体执行时段后，它才会按这个新增日期依据出现。因此月历今天与“今天”页面的总数可能不同。

### 日期与数量边界

- 日期使用 **[当天开始, 次日开始)**。午夜结束的时段不进入次日；午夜开始的点或截止属于次日。
- 仅日期计划保留现有存储约定：开始为当地日初，所选结束日归一化到次日日初前一秒。显示和重开编辑均使用用户选择的最后一天。
- 仅日期截止归一化到当地日末；分钟截止保留指定钟点。不自动重写已经存储的绝对时间来跟随之后的系统时区变化。
- 未来范围顶部按唯一任务计数，包含显示的完成实例；每日组按当天出现次数计数。
- 未来侧栏徽标按范围内仍有未完成实例的唯一任务计数。每日任务只有全部可见实例都完成后，才不再计入范围内待办数量。
- 月历顶部按**当前月份内**的唯一任务统计；相邻月边缘格不会增加本月总数。格内和所选日的任务数应一致；待截止按当天未完成截止任务统计。
- 四象限按原任务计数，一项未结束的每日重复任务只算一项，即便今天实例已完成。

### 搜索范围

- 页面搜索匹配标题、项目名称、标签、上下文和笔记。
- 今天搜索过滤清单/日程和页面分类汇总；页头完成总量仍来自完整今日投影，不能把局部过滤数与全量数混为一谈。
- 明天/未来七天搜索过滤日期组内的行；顶部与日期卡片保留全范围统计。
- 月历只搜索**所选日期**，不搜索整个可见月；月网格与月总量不受它影响。
- 四象限搜索全部四格，显示匹配数与每格匹配/总数；页头仍是工作区全部未完成数。
- “安排已有任务”选择器只搜索标题、项目、标签。候选过滤不同于页面搜索，不能依赖备注在选择器中命中。
- 搜索令选中任务不再可见时清除检查器选择。这里的搜索不是尚待实现的“过滤器管理”。

## 3. 安排执行时段与新建任务

### 安排已有任务

今天、未来页和月历的选择器读取当前工作区可安排任务，包含无日期和逾期待办；排除已结束、目标日重复实例已完成/跳过/未开始，以及该日已有具体计划块的任务。已有计划块的任务可以从日期任务行再安排其他时段。

`DayScheduleEditor` 共用于这些页面以及四象限的“安排”：

- 选择目标自然日内的有效开始和结束；结束可为次日 00:00，开始不能为次日 00:00
- 提示计划重叠，但允许提交不同的重叠时段
- 相同任务、相同开始和结束返回已有 slot，不重复写入
- 只新增 `TaskExecutionSlot`，保留原计划、截止、完成状态和实际记录
- 提交时重新读取原任务，拒绝已结束、删除或不属于当前工作区的任务

当前编辑器创建单日 slot。已有跨日 slot 可以读取并按日裁切，各片段共用原 `slotID`。从今天、未来页或月历任一片段移除，会删除**整个原始执行时段**，不是只删当天片段；原计划和截止保留。“任务计划”块没有 slot 删除按钮。四象限不直接列出 slot，删除需前往相应日期页。

具体计划时长累计每日裁切的分钟块；仅日期范围不折算为全天工时，无结束时间的分钟计划作为点显示且不增加持续时长。不同重叠块分别累计，因此不是去重后的占用时长。

### 默认创建日与草稿

- 今天快捷新建默认今天；明天默认明天；未来七天日期卡片或分组“＋”选择默认日，仍显示全部日期分组。
- 未显式设置计划时，日期页创建使用所选日和日期精度，不自动填截止时间。
- 未来快速草稿已有显式计划时，日期选择不覆盖它，提示“自定计划优先”；标题、优先级等在同一未来面板失焦时保留。
- 月历所选日同时用于页面“新建任务”和全局顶部新建。前后月导航会保留所选日的日号，超出目标月则夹到该月最后一天；“今天”同时重置可见月份和选择。
- 项目、收集箱和四象限等非日期上下文的全局新建不继承上次日历日期。四象限格内新建另有已明示的优先级/截止默认值，见下一节。
- 全局表单允许取消默认计划；提交前取消不写入任务。导航上下文切换会重置快捷草稿和相关搜索，不提供跨页面草稿恢复。

## 4. 四象限规则

由 `QuadrantProjection` 确定两个独立轴：

- **重要 = 高优先级**；中、低、无优先级都归“不重要”
- **紧急 = 截止时间早于本地明天 00:00**；包括今天晚些时候截止及已逾期，恰好明天 00:00 不紧急；没有截止日期不紧急
- 计划时间、执行时段和行动清单不决定紧急程度
- 每格优先按截止从早到晚排列，无截止的在有截止之后，再沿用任务排序

格内“＋”和页面新建菜单明确展示初始优先级与截止：重要格默认高，其他格默认无；紧急格默认今天日终，其他格默认无截止。用户修改后预览实际归属；创建不自动添加计划或 slot。

“更多操作”或右键共享菜单分别调整优先级和截止，指定分钟通过详细编辑设置。修改一个轴保留另一个轴与原计划/slot；没有暗中修改截止的“移动象限”拖拽。安排默认今天，允许明确选择其他日期，安排不会改变象限。

四象限完成是**整项任务完成**，包括适用的下级任务。普通任务完成后离开面板；重复点击完成不会重新打开。每日重复必须确认“完成整项任务并结束重复”，取消不写入；仅完成今天实例应去今天页面。今天实例已完成但整项任务仍未结束时，它继续出现在四象限。

## 5. 日期页完成与检查器

- 今天的普通任务 checkbox 切换整项完成状态；每日任务只切换今天实例。
- 明天和未来七天的行只显示状态图标，没有提前完成未来实例或补录未来实际时间的按钮。
- 月历今天：普通任务可完成/重开；每日任务切换今天实例。
- 月历过去：普通任务为只读完成状态，不通过该行把“现在完成”伪装成过去完成；有效每日实例可补记/撤销其日期令牌。
- 月历未来：不提供完成切换，已有未来完成令牌也不可通过该行重开。
- 所有页面的通用检查器仍可显式修改整项任务状态。未来/月历页面已提示这个范围；检查器计时从现在开始，不补记为所选历史或未来日期。

每日重复目前仅识别 `FREQ=DAILY`，结合开始日、`completedInstances` 和 `skippedInstances` 投影；不是完整 RRULE 引擎。`INTERVAL`、`COUNT`、`UNTIL` 和其他频率尚未实现。分钟模板按自然日平移保留本地钟点；春季缺失时刻向后匹配，结束若不晚于开始则保留模板持续时长；秋季重复时刻选择第一次。

## 6. 今天实际轨与计时

今天的日程展示 00:00–24:00 本地钟点，两条轨道分别用于计划和实际。`DayTimelineLayout` 只裁切几何，不修改原记录：

- 跨日记录只显示与当天相交的部分，编辑器仍打开完整起止日期时间
- 实际统计按每日交集计算；暂停会话只有总 `activeSeconds`，没有暂停段，各日按墙钟交集比例分摊，不能宣称精确还原暂停发生在哪一天
- 活跃计时的起点始终为原会话开始，暂停时终点冻结在暂停时刻；恢复后终点跟随现在，包含墙钟跨度，显示的有效时长仍排除暂停
- 番茄目标线按剩余有效秒数计算，暂停时隐藏；恢复后向后顺延，到目标不会自动停止计时
- 只修改实际记录备注、关联任务或来源时保留原 `activeSeconds`；显式修改起止后按新墙钟范围重算，并验证冲突
- 编辑器支持跨日开始/结束；新建实际记录或修改起止不能结束在未来，逆序/零时长/与已有实际或运行计时重叠应拒绝。旧数据里已存在的未来记录允许仅改备注等非时间字段，不因此重新写造时间
- 编辑器按已编辑字段合并最新记录；另一窗口对相同字段产生冲突时提示重新打开，避免旧草稿覆盖新时间

固定 00–24 刻度是民用钟点布局，不是等比例的真实经过时长轴。夏令时缺失/重复小时不另外增减刻度行，回拨时重复钟点可重合；这一限制与原始记录时长应分开理解。完整 DST 原生几何仍待验收。

## 7. 主题、刷新与验证边界

`PlannerTheme` 以 `NSColor.systemBlue` 提供主操作、完成和选中颜色，旧/新 palette 映射到同一来源；主内容容器继承 `.tint(ModernPalette.accent)`。动态蓝色不承诺固定十六进制值，也不改变用户系统设置。主界面 canvas/panel/项目区/组织栏使用系统语义背景和文字色，随外观切换；仍须验证自定义区域与完整窗口对比度。颜色之外继续保留 checkmark、状态文字、选中背景和辅助功能标签。警告红色、实际轨或计时语义色、项目/标签自定义色不属于完成色，不应全部涂蓝。主题源码与待验收项见 [theme-consistency.md](theme-consistency.md)。

日期主视图与侧栏通过每分钟 `TimelineView` 刷新；日期缓存包含本地日初和日历信息，任务变更清缓存。午夜、系统时区变化、打开弹窗时导航、重复提交与窗口恢复仍需在 macOS 上实测，不能从数据层推断原生事件顺序正确。

本轮没有新增数据库 schema，沿用已有执行时段与 SwiftData/Codable 持久化。源码与回归用例已补充；Linux 静态检查和 Python 推导不是 Swift 编译、Swift 测试、原生视觉或交互验收。过滤器管理、完整 RRULE、四象限跨格拖动和月历拖拽改期不在当前完成范围。

### Liquid Glass 的使用范围

本轮在 macOS 26 目标上使用真正的 SwiftUI `glassEffect(.regular)`，由 `LiquidGlassStyles.swift` 的 `plannerControlSurface` 统一处理辅助功能分支：

- 玻璃用于导航/控制层。`ModernTopBar` 由 `GlassEffectContainer(spacing: 8)` 协调胶囊工具按钮；`ModernSourceSidebar` 作为单层导航表面，月历前后月/今天控制共用一块玻璃
- 不给每个任务行、内容卡、编辑面板再套玻璃；这些内容保持动态不透明语义背景。`SearchField` 使用实色输入表面，不用 clear glass
- 减少透明度或增加对比度时，不依赖系统自动猜测：显式切换不透明语义 surface 与可辨识描边
- 减少动态效果时关闭 interactive glass，相关自定义缩放/位移动效退为静态或轻量透明度变化；它不意味着一切状态变化都不再发生
- 完成与选中仍用统一蓝色，玻璃不承担任务状态语义；材质也不改变任务日期、slot 或实际记录

`LiquidGlassRulesTests` 的三个测试声明覆盖实色回退与交互动效规则，尚未执行。是否有不恰当玻璃叠层、文字透底、滚动重绘问题、禁用态/hover/focus 不清楚，需要原生截图和操作验证，不能从 API 接线或测试声明推断视觉通过。

## 8. 设置、本机偏好与数据保护

`PlannerSettingsView` 使用原生 Settings 场景，通用/外观/数据/关于四页共享应用的同一个 `PlannerPreferences`，不创建第二份独立设置状态。

- 外观（跟随系统/浅色/深色）、今天默认模式、番茄默认分钟和设置当前页签写入本机 `UserDefaults`，不包含于任务 JSON 备份
- 默认工作区沿用数据库元数据，下次启动使用；设置今天默认模式立即影响今天，重启保留
- 番茄默认分钟范围 1–180，默认 25；新会话使用它，正在运行的目标不受设置修改影响，显式指定时长仍优先
- 数据页显示实际存储位置，提供 Finder 定位、JSON 导出/恢复及 Obsidian 迁移；关于页读取当前构建版本
- 导入/迁移属于**替换整个数据库**，不是合并，包括全部工作区、项目、任务、实际记录、日志和垃圾箱，以及输入文件的计时状态（如有）
- 替换前明确确认并自动导出当前快照到数据库目录的 `Backups/before-replace-…json`；备份或写入失败不得发布新数据库。自动备份可能含全部个人数据，不能上传公开仓库
- 当前存在运行或暂停计时时拒绝替换，需用户先停止并保存；取消选择器或确认安静返回
- 写入 generation 防止替换前排队的旧 debounce 快照覆盖恢复后的新库；成功后重置过期导航/选择

上述为当前源码保护设计，失败路径与真正的磁盘/窗口行为仍未在本轮 macOS 运行。只有单独工作区不足以安全测试“替换全部数据”，必须使用整个数据库均为虚构数据的独立测试环境。

## 9. 共享任务操作与命令边界

`TaskContextActions` 与 `TaskActionServices` 提供查看详情、完成/重开、安排时段、优先级、截止、详细编辑、复制单项和删除入口，按被操作的稳定任务 ID 在执行时重读当前工作区数据。

- 日期行携带 `.day(day)` 作用域，不因当前侧栏或旧选中项而误完成整项。普通列表和四象限使用 `.task`
- 今天每日完成只切当天令牌；过去普通任务不可经日期菜单改写完成，未来完成操作在共享右键中隐藏、在全局命令中禁用。整项每日完成先确认结束整项及其子任务
- 共享菜单“安排时段…”对未来行默认该日，对普通/今天默认今天，对历史行至少从今天起；明确显示目标日期。月历日期行原有安排入口仍按其选日编辑，两种入口须按弹窗日期区分
- 优先级与截止快捷项只改命名字段；选中同值不应用旧任务快照覆盖其他新修改
- 复制只复制当前这一项，保留适用原字段和同级归属，生成新 ID；已结束任务的副本重开。子任务、实际记录、slot、活动历史与每日完成/跳过令牌不复制
- 删除先确认，任务及子任务和关联实际记录移入垃圾箱，可恢复。倾倒垃圾箱另有永久删除警告；没有实现任务级 Undo，不宣称 ⌘Z 可还原这些操作
- `PlannerTaskCommands` 注册 ⌘N 新建、⌘D 复制选中任务、⌘K 完成/重开、⌘Delete 请求移入垃圾箱；⌘, 由原生 Settings 提供。任务命令要求主内容焦点、有效同上下文选择，排除文本编辑、归档与专注模式，并按日期页计算完成范围。按照手工清单验证焦点、空选择、工作区切换和多窗口，不能仅凭源码判定键盘行为通过
