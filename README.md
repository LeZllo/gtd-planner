# GTD Planner

[English](README.en.md) · 中文

GTD Planner 是一个面向 macOS 的原生 GTD 任务管理工具，将任务收集、项目拆解、计划安排、实际专注和复盘放在同一个工作流中。

项目目前处于早期公开开发阶段，功能会持续迭代。

## 最新进度

最近更新：今天、明天、未来七天、四象限和月历五个页面已接入主界面，共用任务数据、检查器与执行时段服务，并统一主操作、完成和选中态的蓝色主题。

- **今天**：任务搜索、清单/日程切换、安排已有任务、完整 00:00–24:00 计划轨/实际轨、15 分钟或 5 分钟拖拽吸附，以及实际记录编辑入口。
- **明天 / 未来七天**：按本地自然日分组；未来七天从明天起，不含今天。跨日任务可在多天出现，顶部按任务去重，侧栏统计仍有未完成实例的任务。
- **四象限**：显示当前工作区全部未完成任务；高优先级表示重要，今天截止或逾期表示紧急。可搜索、新建、明确修改优先级或截止时间、安排时段、查看详情和完成整项任务。
- **月历**：完整周网格、前后月和今天导航、跨月选日、按所选日期新建和安排、搜索当天任务；完成入口区分今天、历史每日实例和未来计划。
- **共享规则**：添加/移除执行时段不改原计划或截止时间；相同 slot 重复提交幂等；实际记录不能新建到未来。跨日实际记录保留完整起止，只在当天轨道和汇总中裁切。
- **设置与任务操作**：原生设置包含通用/外观/数据/关于，持久化默认工作区、今天模式、外观和番茄分钟；共享任务菜单提供按日期作用域完成、安排、编辑、复制单项与删除确认。
- **数据替换保护**：JSON 恢复与 Obsidian 迁移先确认替换全部数据并自动备份；运行/暂停计时中禁止替换，取消不写入。
- **Liquid Glass**：macOS 26 原生 `glassEffect(.regular)` 用于工具栏与导航控件，顶部用 `GlassEffectContainer` 协调；内容列表、任务卡、编辑表面和搜索输入保留动态不透明背景。减少透明度/增加对比度时切换实色，减少动态效果时关闭交互玻璃动效。
- **主题一致性**：主操作、任务完成 checkbox、选中态与默认原生控件 tint 共用动态系统蓝色；警告、计时阶段和用户自定义项目/标签颜色保留各自语义。

这些是当前源码范围，不是本轮运行通过声明。当前工作环境为 Linux，没有 Swift 工具链和 macOS SDK，尚未执行本轮 `swift test`、应用构建或原生验收。历史“60 项测试通过”和第一阶段 checkpoint 不代表这一版完整通过。

本地验证请从 [逐页手工验收步骤](MANUAL_QA.md) 开始；另见 [质量验证状态](design-qa.md)、[五页计划设计](docs/planning-design.md) 和 [主题一致性说明](docs/theme-consistency.md)。

## 已实现功能

### 工作区与项目

- 工作区的创建、切换和删除
- 设置默认工作区
- 项目添加、调整和排序
- 项目分区的设置与管理
- 任务分区和多级下级任务

### 任务与时间

- 任务状态、优先级、任务标签和任务笔记
- 任务计划时间与截止时间
- 实际专注时间的记录、补录、编辑和删除
- 今天执行视图：搜索、清单/日程模式、今日任务分类、具体执行时段和完成进度
- 今天视图中的 00:00–24:00 计划轨与实际专注轨；跨日记录编辑和暂停计时显示
- 明天/未来七天计划面板：逐日分组、已有任务安排、具体执行时段、任务去重汇总和按所选日期创建
- 四象限：按优先级与截止时间分类、搜索、新建、安排和明确调整任务字段
- 月历：前后月导航、选日、当天任务搜索、新建、安排和符合日期规则的完成操作
- 甘特图与任务树保持一致的项目规划视图

### 执行与记录

- 标签管理
- 番茄钟与正计时，支持暂停、继续和停止
- 垃圾箱：可恢复误删除的项目、工作区等内容
- 操作日志：查看软件中的操作记录
- 原生设置四页，保存外观、今天默认视图和新番茄默认时长
- 共享任务右键/更多操作，复制单项与删除到垃圾箱

### 数据与导入

- 原生 SwiftUI macOS 界面：组织栏、工作区、项目树、任务列表和检查器
- SwiftData 本地持久化
- JSON 备份导入与导出
- 从 Obsidian 资料库导入 GTD 任务、项目层级、任务笔记和实际时间记录

## 待完成部分

- macOS 原生构建、逐页交互、视觉与辅助功能验收，以及后续交互优化

- macOS 26（Tahoe）或更高版本
- Swift 6.2 工具链；也可以使用支持该工具链的 Xcode 版本
- 当前版本不依赖网络包或远程服务

## 构建和运行

在项目根目录执行：

```sh
swift test
./build-app.sh
open "GTD Planner.app"
```

`build-app.sh` 会在项目根目录生成 `GTD Planner.app`。构建脚本使用本地签名，应用目前没有 Apple Developer ID 签名和公证；首次运行时 macOS 可能显示安全确认。

## 数据与隐私

应用数据默认保存在：

```text
~/Library/Application Support/GTD Planner/GTD Planner.store
```

数据保存在本机。首次启动只创建空的默认工作区，不会自动写入演示任务或上传用户资料。

恢复 JSON 或从 Obsidian 迁移会替换全部任务数据库，包含所有工作区；继续前会确认并自动在数据库同目录的 `Backups` 留存旧快照。自动备份同样可能含私人信息。外观、今天默认模式和番茄分钟等本机偏好不在 JSON 备份中，默认工作区仍属于数据库元数据。

从 Obsidian 导入是一次性迁移操作：应用读取 `type: gtd-task` 任务、项目层级、任务笔记和 `gtd-time-entry` 实际记录，运行时数据由 SwiftData 管理。

请不要把个人数据库、JSON 备份或包含真实任务的资料库提交到 GitHub。

## 图标与字体

项目没有内置自定义字体、图标文件或第三方图标库。

- 界面图标通过 SwiftUI 的 `Image(systemName:)`、`Label(..., systemImage:)` 和 SF Symbols 名称调用。
- 文字通过 SwiftUI 的系统字体接口（例如 `.font(.system(...))`）渲染。
- 项目不重新分发 SF Symbols 或 macOS 系统字体；相关内容仍受 Apple 的许可条款约束。

## 当前限制

- 当前仅支持 macOS 26 及以上版本。
- 任务操作没有全局 Undo；删除后使用垃圾箱恢复，不应依赖 ⌘Z。设置和快捷键接线仍待原生焦点/多窗口验收。
- 暂未提供 Developer ID 签名、公证和预编译下载包，使用者需要本地构建。构建脚本通过 `swift build --show-bin-path` 查询当前工具链的实际产物目录；Intel Mac 打包尚未验证。
- 当前持久化、计时和日志服务仍由应用协调器统一管理，后续会继续拆分和完善。
- 每日重复目前仅识别 `FREQ=DAILY`，结合开始日期、已完成实例和跳过实例投影；尚未实现完整 RRULE 语义（如 `INTERVAL`、`COUNT`、`UNTIL` 和其他频率）。
- 跨日专注统计不修改原始记录。暂停计时只存储总 `activeSeconds`，没有暂停分段，因此各日有效时长按墙钟交集比例估算。
- 计划时长累计具体时段；日期范围不会自动换算成全天工时，不同的重叠时段仍会分别累计。
- 今天日程以本地钟点显示固定 00–24 刻度；夏令时回拨的重复小时不是两条独立刻度，不能把像素高度当作实际经过时长。
- 自动化测试主要覆盖数据层和交互回归；本轮测试尚未执行，完整的视觉、键盘、辅助功能与系统窗口验证仍需要在 macOS 上进行。
